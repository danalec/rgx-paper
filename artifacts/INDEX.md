# Reproducible-artifact index

Every quantitative claim of this paper reduces to a file in the `rgx`
repository's `benchmark/` and `scripts/` trees. This index lists them with
their digests so a reader can reproduce a table by checking out the named
tree and rerunning the named script. The repository is at
[`github.com/danalec/rgx`](https://github.com/danalec/rgx); the canonical
host-tagged transcripts are mirrored in
[`github.com/danalec/rgx-paper`](https://github.com/danalec/rgx-paper) under
`artifacts/` once they are exported here.

## What this index is not

This index does not contain raw byte counts or per-round millisecond
samples — those are in the transcripts. It is the table of contents that
says *which file is the source of truth* for every quantitative claim, so
that a reader who asks "where is the number that backs `tab:predictions`
row 4" can answer with a path instead of a sentence.
